# BRAIN LAB — ночь поиска «того самого мозга» (HAAP)

Дата: сессия 2026-08-23 (ночь). Задача: «мозг взрывается / умирает» на HAAP —
найти причину и довести HAAP до игрового качества: стабильность + обучение +
живость.

---

## 1. Почему мозг взрывался: цепочка из 6 багов

| # | Баг | Где | Эффект |
|---|-----|-----|--------|
| 1 | `physiology::template()` не задавал `P::dt` → колонка = 0.0 | `src/physiology.rs` | — |
| 2 | Конфиг `HaapSynaptic { dt_ms: DT_MS }` (=0.5, а не 0.05) | `src/brain.rs` | `run_haap` (runner.rs:1863) видит расхождение и **перезаливает dt=0.5 навсегда**. Задуманные 0.05/500 подшагов никогда не работали → би-стабильность «взрыв/тишина» (собственный комментарий brain.rs это предсказывал!) |
| 3 | Дофамин писал веса в LIF-масштабе: клэмп к `w_max=3` при рабочих весах HAAP ~0.2 | `Brain::apply_dopamine` | Один тычок награды = синапс в 15× сильнее врождённого |
| 4 | Логнормальный хвост grown-весов (медиана 2, хвост 50+) без клипа | построение CSR | Один хвостовой синапс единолично пинит нейрон → судорога |
| 5 | Пластичная рекуррентность S→S | `arena_brain` | Дофамин загонял её в кап → сенсорный пул горел самоподдерживающейся судорогой без входа |
| 6 | Награда детонировала в старте следующего эпизода | цикл эпизода | eat → break → дофамин приходит при максимальном сенсорном драйве нового эпизода → цепная реакция |

**Диагностика**: временный бин показал `dt колонка до step = 0.0, после = 0.5`
— курок найден за один прогон.

## 3. Эксперименты

### Сетка syn_scale × syn_cap (арена, 6 эп., судорога = >3000 сп/тик)

Стабильность живёт на диагонали **cap ≈ 2.5–2.7 × scale**; cap 0.6 пробивается
хвостом при любом scale; scale ≥ 0.35 судорожит всегда.

Победитель: **scale=0.15, cap=0.40** — 100% еды, среднее 130 тиков, worst 755.

### Обучение
- Пер-тиковый гомеостаз **пинит среднее пути** при любом rate (0.25 и 0.08 дают
  бит-идентичные траектории): обучение перераспределяет веса внутри суммы.
  Это паритет с LIF: poc-arena на LIF тоже показывает w(S→M) 2.0881→2.0881.
- **Рефлекс-протокол на HAAP: w(S→M) +295%** (0.18→0.71), латентность 1.6→0.0 мс,
  рефлекс жив, без судорог. Механика 3-факторной пластичности на HAAP полностью
  рабочая. Для измеримого обучения: `homeo_every_ticks=0` (гомеостаз только при
  дофамине), схема без рекуррентных петель.
- LIF после отката глобального гомеостаза: рефлекс +92.9%, контроль −0.2%.

### Живость (когнитивная схема 9 регионов, HAAP)
Финальное состояние режимов:
- **Сон**: полная тишина по всем регионам (пейсмекеры разряжены до 1/3 +
  ослабленная HAAP-реверберация WS→WS 0.04, WM→WM 0.06).
- **Ignition**: кий зажигает WS 5.3 сп/тик, память записывается.
- **Плато памяти**: WM держит ~6 сп/тик неограниченно (h-аттрактор архетипа
  Memory). Осознанное решение: мысль держится, пока существо ею занято;
  сброс — `Brain::hyperpolarize(&[WS…WM], …)` (так делает delayed.rs между
  пробами; для игры — события «наелся/уснул»).
- **Стресс**: worstTick=75, вспышка затухает в стабильный фон ~23 сп/тик
  («возбуждение»), судорог нет.
- Пейсмекер изолированно (pm-tune): K-параметры дают честные burst-паузы;
  сплошной регион осцилляторов сеть синхронизирует в тоник — потому разряжен.

## 7. Органный мозг (день): HH спина + HAAP средний + LIF кора

Реализовано: `src/organs.rs` (`OrganBrain`, `Axon`, `WorldInputs`) +
`poc-organs`. Органы — отдельные `BrainRunner` со своими dt (HH/HAAP 0.05 мс ×
500 подшагов, LIF-кора 0.5 мс × 50); связь — межорганные аксоны с задержкой
1 мировой тик: спайки пре-группы за тик × вес → ток в пост-орган на следующем
тике. Кора — полноценный диома-`Brain` (LIF-α + дофаминовая пластичность).

Спина на **проводимостных** синапсах (`hh_synaptic` + `build_receptor_types`):
токовые одиночные пульсы физически не раскачивают мембрану HH за шаг.

Результаты PoC:

| Опыт | Результат |
|---|---|
| A. HH рефлекс | латентность боли→мотор **2.75 мс**, точный |
| B. Мотивация | голод среднего мозга → активность **+62%** |
| C. Кора учится | награждённый путь **+160%**, ненаграждённый +15% |
| Контроль D=0 | веса неподвижны |

Ключевые уроки:
- **Окно допустимости**: след τ_e=1000 мс доживает от ненаграждённой пробы до
  следующей награды и обобщается (+15% на B). Лечится явным закрытием окна —
  добавлен `Brain::clear_eligibility()`.
- Конвергенция важна для LIF-кор: 1 пресинапс весом 1.4 не зажигает out;
  3 пресинапса × 2.0 (рабочий диапазон арены) — зажигают.
- Пейсмекерный микс среднего мозга (K-параметры, 1/3 осцилляторов) даёт живой
  фон 4.7 сп/тик и отзывчивость на драйв без судорог.

Тест `organs_reflex_fast_and_cortex_learns` закрепляет всё троё (16/16 зелёные).

## 9. Исправлен кернел обучения движка (dopamine_weight_update)

**Баг**: клэмп `[w_min, w_max]` применялся ко ВСЕМУ массиву при каждом вызове —
синапсы с нулевой eligibility (замороженные пути, критические окна) молча
резались к границам. В dioma grown-хвост даёт врождённые веса до 22 при
w_max=6 — каждая награда стачивала их, даже если синапс не участвовал.

**Фикс** (taas-checkmate, `kernels/dopamine/mod.rs`): клэмп — часть
ОБНОВЛЕНИЯ. SIMD: `participates = e.abs() > 0 → blend(updated, w)`; scalar
tail: `if delta == 0 { continue; }`. Синапсы с e=0 сохраняют значение
бит-в-бит, включая лежащие вне границ.

**Семантические находки попутного дебага** (легли в dioma/brain.rs):
1. `thaw_at=usize::MAX` для frozen_pairs теперь честный (было 0 — дофамин и
   гомеостаз тихо трогали «врождённые» пары).
2. Тормозные пути (I→M) должны оставаться ПЛАСТИЧНЫМИ по дофамину: награда
   ослабляет торможение через LTD — заморозка I→M запирает моторы после
   усиления S→I (рефлекс «умирал»). Заморожены только явные frozen_pairs.
3. Гомеостаз — exc-only суммы (знак в одной сумме ломал масштаб HAAP-арены).

**Регрессия**: `dopamine_weight_update_preserves_zero_eligibility_weights`
(движок, 881/0). Dioma вернулась на канонический SIMD-кернел вместо ручного
цикла. Числа: poc-reflex **+95.4%** (ручной цикл давал +92.9% — клэмп больше
не режет пластичные хвосты при нулевом Δ), контроль −0.2%, арена/органы — в
норме, smoke 16/16, clippy 0.
