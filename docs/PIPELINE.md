# Канонический игровой тик (pipeline)

Все новые миры dioma строятся по одной фазировке. Мир задаёт **правила и
данные**, но не изобретает собственный жизненный цикл.

## Фазы тика

| # | Фаза | Ответственность |
|---|------|-----------------|
| 1 | `regrow_food` | мир восстанавливает съеденные ресурсы |
| 2 | `sense` | сенсорика **всех** существ до любых движений этого тика |
| 3 | `steer` | выбор курса: к цели / блуждание, шум поворота |
| 4 | `move_forward` | смещение по heading со скоростью от крови |
| 5 | `collide_walls` | столкновения, отражение, боль |
| 6 | `try_eat` | взаимодействие с ресурсами |
| 7 | `metabolize` | локусы → `Blood::update()` → жизнь/смерть |

Ключевые инварианты:

- Сенсорика (фаза 2) снимается до начала движений — порядок обхода существ
  не влияет на то, что они видят.
- Внутри фаз 3–7 сущности обрабатываются последовательно; побочные эффекты
  фазы 6/7 (съеденная еда) видны следующим существам только в следующем
  тике их сенсорики.
- Биохимия (`Blood::update`) вызывается ровно один раз за тик на существо,
  в конце его конвейера.
- Награды/обучение (когда появятся) применяются после фазы 7, отдельным
  проходом, чтобы пластичность не смешивалась с механикой движения.

## Эталонная реализация

`src/game/mod.rs` — `Scene::step()`: каждая фаза — именованный метод
(`regrow_food`, `sense`, `steer`, `move_forward`, `collide_walls`,
`try_eat`, `metabolize`). Новые сценарии копируют эту структуру.

## Миграция legacy-миров

`world::arena`, `world::free_life`, `world::ecosystem`, `world::side`
пока содержат собственные циклы. Они переводятся на конвейер постепенно:
сначала вычленить одноимённые фазы внутри существующего `step`, затем
подключить общий runner. До миграции их поведение считается legacy.
