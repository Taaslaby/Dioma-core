# dioma-engine

Игровой runtime живых существ Dioma.

## Что здесь находится

- **`engine`** — нейроны, пластичность, рост и наследуемая проводка;
- **`body`** — органы, кровь, глюкоза, голод, боль и восстановление;
- **`creature`** — сенсоры → мозг → действие;
- **`env`** — комнаты, двери, CA-вещества и климат;
- **`script` / `world`** — скриптовые игровые объекты, события и таймеры;
- **`sim`** — арена и эволюция.

## Быстрый пример

```rust
use dioma_engine::creature::{Creature, Sense};

let mut animal = Creature::new(42);
let action = animal.tick(&Sense {
    smell_l: 0.8,
    ..Sense::default()
});

println!("steer={}, drive={}", action.steer, action.drive);
```

## Границы ответственности

`Creature` не знает о координатах и ягодах. Он получает только `Sense` и
возвращает `Action`. `Arena` отвечает за движение, столкновения, еду и климат.
Рендер не входит в этот crate и может подключаться сверху.

## CPU и GPU

`Creature::new` использует CPU-путь. `Creature::new_gpu` использует GPU-мозг,
если доступен адаптер, иначе SiMuse делает CPU fallback. GPU выгоден прежде
всего на больших batch-ах; для одного маленького мозга CPU часто имеет меньшую
задержку.

## Проверка

```bash
cargo check -p dioma-engine
cargo test -p dioma-engine --lib
```

Тесты должны проверять не только типы, но и поведение: обучение, сон,
наследование, движение, питание, климат и детерминизм.
