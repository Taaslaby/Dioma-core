# PoC: «Выращенный рефлекс + пластичность»

Головной эксперимент, доказывающий связку **prometheus-grow → pillars-connectome → дофаминовая пластичность** в одном конвейере. Всё делается как новый пример `reflex_poc` в `crates/pillars-connectome/examples/` (по образцу `genome_to_gamma.rs` и библиотеке `grow_engine.rs`).

## 1. Выращивание рефлекторной дуги (много-морфогенный grow)

Три региона клеток в `World` (~120 нейронов):
- **S** — сенсорные (E, секретируют морфоген `"S"`), ~40 шт.
- **I** — тормозные интернейроны (секретируют `"I"`), ~20 шт.
- **M** — моторные (секретируют `"M"`), ~40 шт.

Наведение по морфогенам (в grow пока только один морфоген на прогон — добавляем по существующему паттерну `Secretor`/`ChemoAttraction::new(substance_id)`):
- аксоны S: `ChemoAttraction::new("M")` — тянутся к моторным (безопасный путь: S→I→M вместо прямого, раз I тормозные — отдалим S и M, интернейроны между ними, по сути наоборот для рефлекса отдёргивания)
- аксоны I: `ChemoAttraction::new("M")`
- аксоны M: локально, `ChemoAttraction::new("M")` с коротким `max_len_um`

Проверка структуры: доля синапсов S→M / S→I / I→M vs случайный контроль (переключение целей, как `shuffle_targets` в grow_engine).

## 2. Динамика + обучение

- Мост в `ConnectomeData::new` + `BrainRunner::new(conn, NeuronConfig::lif(...))` — по образцу `grow_engine::build_runner`.
- Стимул «боль»: `external_I` в сенсорные нейроны на ~20 мс.
- Рефлекс: считаем отклик моторных через `firing_rates_group`.
- Пластичность: `pillars::api::neurons::DopamineSTDP` поверх публичного `runner.connectome.values` (шаг eligibility каждый шаг, `apply_dopamine` при награде).
- Гомеостаз, чтобы не развалилось: `kernels::learning::sorn::synaptic_normalization` + `intrinsic_plasticity` после каждого блока обучения.

## 3. Протокол эксперимента и метрики

Фазы: (A) базовый рефлекс → (B) 2000 шагов STDP-без-награды → (C) пары «стимул → правильный моторный ответ → дофамин» ×N → (D) финальный тест.

Печатаем таблицу:
1. Латентность стимул→моторный ответ в каждой фазе (рефлекс должен сохраниться, ≤ ~30% деградации).
2. Средние веса по путям S→M, S→I, I→M в каждой фазе (дофамин должен избирательно усилить награждаемый путь).
3. Контроль: тот же геном, дофамин=0 — усиления нет.
4. E/I баланс (частоты E и I популяций) — нет судорог/молчания.

Критерий успеха: рефлекс переживает фазу B, фаза C даёт статистически видимое усиление нужного пути относительно контроля.

## 4. Технические детали

- Крейт: пример в `pillars-connectome/examples/reflex_poc.rs`, переиспользуем `prometheus-grow` через dev-dependency (уже есть у grow_engine).
- Мелкие правки в `pillars-connectome/src/grow_engine.rs` не делаем — выносим конфигурацию роста в сам пример (или новый модуль `grow_engine::reflex` при необходимости переиспользования).
- Тест: один интеграционный тест `tests/reflex_poc.rs` (grow детерминирован по seed → проверяем, что синапсы S→M существуют и рефлекторный отклик воспроизводим).
- Никаких изменений в существующих крейтах не планируется, кроме возможного расширения `GrowConfig`-подобной структуры в примере.
