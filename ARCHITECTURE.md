# Архитектура диомы

Движок выращиваемых спайковых существ поверх taas-checkmate.
Слои зависят только вниз: мир знает о телах, тела о мозгах, мозги о геноме.

```
                ┌─────────────────────────────┐
                │   ui (обсерватория egui)    │
                └──────────────┬──────────────┘
                ┌──────────────┴──────────────┐
                │  world  арена/жизнь/экосистема│
                └──────────────┬──────────────┘
                ┌──────────────┴──────────────┐
                │  mind   мост в karmac        │
                └──────────────┬──────────────┘
                ┌──────────────┴──────────────┐
                │  body   органы·кровь·жизнь   │
                └──────────────┬──────────────┘
                ┌──────────────┴──────────────┐      heritage (.taas,
                │  engine ЯДРО: геном→нейроны  │◄──►  потомство, мутации)
                └─────────────────────────────┘
                               ▲
                   taas-checkmate (pillars, karmac, prometheus)
```

## Слои

### engine — ядро (чистые нейроны и геном)

| модуль | отвечает | ключевые типы |
|---|---|---|
| `engine/genome` | геном: связи + регионы + гены правил | `Grown` |
| `engine/grow` | рост коннектома из layout (мост prometheus-grow) | `Layout`, `grow()` |
| `engine/neurons` | спайковая динамика + дофаминовая пластичность + гомеостаз | `Brain`, `PlasticityParams` |
| `engine/rules` | **Пифия**: ВМ правил динамики клеток, гены шаблонов | `RuleGene`, `PythiaUnit`, `compete()` |
| `engine/graph` | тропическая перестройка живого графа (трофическое поле) | `tropic_rewire()`, `TropicField` |

Инварианты ядра: не знает ни о еде, ни о температуре, ни об экранных пикселях.

### body — организм

`organs` (спина+средний мозг+кора), `metabolism` (кровь, химия),
`physiology` (температура, Q10, архетипы), `life` (`OrganSim` —
пошаговый цикл восприятие→мозг→действие, состояния покоя).

### mind — разум

`bridge` (`CreatureMind`): каналы тела → GNW → политика действий,
обучение W2.

### world — мир и задачи

`arena` (арена с едой и агентами), `free_life` (свободная жизнь,
`WorldSim`), `ecosystem` (популяция: рождение/смерть/отбор),
`exam` (экзамен: эффективность/экономика/шум/темперамент),
`delayed` (задача с задержкой: workspace↔память).

### heritage — наследственность (сквозной слой)

Сохранение существ в `.taas` (сид + выученные CSR + W2 + гены правил),
вливание наследства (`load_creature_into`), потомство со мутациями
(`spawn_child`: веса σ=0.05, W2 σ=0.02, гены правил σ=0.08).

## Три механизма поверх спайков

1. **Гены правил (Пифия)** — эволюция меняет ДИНАМИКУ клеток
   (порог/утечка/привыкание), а не только веса. Доказано: одна анатомия,
   разные гены → смелый решает при слабом стимуле, осторожный ждёт
   (`evolved-rules`, `dynasty`).
2. **Тропическая перестройка** — граф живой: слабые синапсы тихих путей
   рассасываются, ростки прорастают между активными клетками
   (`evolved-rules`, часть B).
3. **Сон-консолидация** — снимок выученного после дня; ночь возвращает
   дрейфовавшие веса к снимку (15× точнее держит навык) (`brain.rs`,
   `memory_snapshot/recall`; `evolved-rules`, часть C).

## Бины

Активные протоколы: `dynasty`, `evolved-rules`, `skinner-box`,
`conditioning`, `exam`, `poc-heredity`, `maze-test`, `brain-battle`,
`sardana-probe`, `evolution`.
Обсерватории: `observatory`, `observatory-eco`.
История ранних PoC — заморожена в `archive/bins/`.

## Соглашения

- Русские термины движка: регион (не «доля»), трофический сигнал,
  тропическая перестройка, сон-консолидация, конкуренция (WTA).
- Внешние зависимости только от крейтов taas-checkmate + rayon/egui;
  форков движка нет — всё через публичные API.
- Детерминизм: рост и мутации выводятся из сидов; в файл пишется только
  выученное + гены.
