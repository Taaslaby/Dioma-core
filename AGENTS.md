# AGENTS.md — dioma (Rust)

Референсная реализация движка. C#-порт (репо `dioma-engine`, пакет
`com.dioma.engine`) сверяется с ней побайтово, поэтому здесь любое изменение
чисел — это изменение эталона для второй реализации.

## Проверки

```
scripts/verify.sh          # cargo check + 220 тестов crates/dioma-engine
scripts/verify.sh all      # плюс тесты SiMuse (отдельный воркспейс, минуты)
scripts/verify.sh fmt      # cargo fmt --check
scripts/verify.sh lint     # clippy -D warnings
scripts/goldens.sh         # регенерация 9 эталонов в ../dioma-engine
```

Тесты крейта гоняются **в release**: в debug мозг на порядок медленнее, и
сценарии со сном и голоданием не укладываются в разумное время (145 с против
9+ минут).

## Что ломается, если не знать

**Это не воркспейс, и так задумано.** `crates/SiMuse` имеет свой
`[workspace]` с наследованием (`workspace = true` в манифестах его крейтов);
вложенные воркспейсы это ломают. Отсюда следствие: `cargo test -p dioma-engine`
из корня не работает («requires dev-dependencies and is not a member of the
workspace») — нужно зайти в `crates/dioma-engine`.

**`target-cpu=native` в `.cargo/config.toml`.** Бинарники непортируемы между
машинами. Для CI это придётся снять или зафиксировать конкретный
целевой процессор.

**Эталоны для C# порождают только экспортёры.** `src/bin/export_{connectome,
bio,taas,learning}.rs` пишут 9 файлов в `dioma-engine/Tests/Editor/Data`.
Править эти файлы руками нельзя: паритет тогда проверяет сам себя. Если
`scripts/goldens.sh` показал изменение — сначала прогони проверки C#-порта,
и только потом коммить оба репо вместе.

**`.taas` обязан быть побайтово воспроизводимым.** Поэтому в `taas-format`
метаданные лежат в `BTreeMap` (порядок ключей в JSON манифеста стабилен), а
`export_taas` фиксирует `created` через `TaasWriter::created()` вместо часов
машины. Вернёшь `HashMap` — эталон начнёт «меняться» на каждом прогоне.

**`homeo_exclude_pre` надо передавать дважды.** В `export_connectome` этот
список (регионы-ПРЕ, исключённые из гомеостаза; в stage-C это кора) идёт и в
JSON коннектома, и в конструктор Rust-мозга. Если передать только в JSON,
референс и порт считают гомеостаз по-разному, и паритет stage-C рассыпается
примерно на 65-м тике — далеко от места ошибки.
